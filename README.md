# Trading platform (static site + optional Supabase)

Plain HTML/CSS/JS: no build step, no dependencies to install.

## Run it locally
```bash
python3 -m http.server 8080      # or: npx serve .
# open http://localhost:8080
```
Open it through a server (not by double-clicking the file): Chrome restricts some features on `file://` pages.

## Put it online (GitHub Pages)
1. Push this folder to a GitHub repo (branch `main`).
2. Repo **Settings → Pages → Source: GitHub Actions** (the workflow in `.github/workflows/pages.yml` deploys it).
3. Optional but recommended: a custom domain (Settings → Pages) so `robots.txt` and `sitemap.xml` sit at the domain root.

## Connect Supabase (data sync, real accounts, admin panel)
Follow `SUPABASE-SETUP.md`, or in one command:
```bash
python3 tools/setup-site.py --supabase-url https://xxxx.supabase.co --anon-key YOUR_ANON_KEY
```
Then in Supabase → Authentication → URL Configuration set **Site URL** to your live address.

**Not connecting?** Open `status.html` on the same site and the same browser. It tests the browser, your keys, the Supabase library, the database tables and the price feeds, and tells you what to fix. The usual causes:
- `sb-config.js` still empty, or the URL/key copied wrongly.
- `supabase-schema.sql` was not run (tables missing).
- Supabase **Site URL** doesn't match the address you open.
- An ad blocker / firewall blocking `cdn.jsdelivr.net` or `*.supabase.co`.
- The free Supabase project was paused (open the dashboard to resume it).
- The page was opened as `file://` instead of through a server.

## Google / SEO
```bash
python3 tools/setup-site.py --url https://www.your-domain.com --brand "Your Brand Name"
```
This sets the canonical URLs, Open Graph tags, structured data, `robots.txt`, `sitemap.xml` and the brand name in the static HTML. Then:
1. Add the site in **Google Search Console** and submit `https://www.your-domain.com/sitemap.xml`.
2. Optionally add an `og-image.png` (1200×630) and an `og:image` tag for nicer link previews.

Public pages (`index.html`, `signup.html`) are indexable. Account, wallet, sign-in, reset and admin pages carry `noindex`.

## Admin
- Sign in at `admin-login.html` with an account whose `profiles.role = 'admin'` (see `SUPABASE-SETUP.md`).
- Without Supabase the admin panel is a demo only (checked in the browser, not secure).

## Files
| File | Purpose |
|---|---|
| `index.html`, `signup.html`, `signin.html`, `reset.html` | Public pages |
| `account.html`, `markets.html`, `trade.html`, `wallet.html`, `portfolio.html`, `orders.html`, `history.html`, `settings.html` | Account area (generated by `tools/build-pages.py`) |
| `admin.html`, `admin-guard.js`, `admin-ui.js`, `admin-app.js`, `admin-login.html` | Admin panel (loaded only after the server confirms an admin) |
| `script.js`, `dashboard.js`, `feed.js`, `converter.js`, `supabase.js`, `sb-config.js` | App code |
| `supabase-schema.sql`, `SUPABASE-SETUP.md` | Backend |
| `status.html` | Connection diagnostics |

To change the account-area layout, edit `tools/build-pages.py` and run `python3 tools/build-pages.py`.

## Browser support
Current Chrome, Edge, Firefox and Safari (Chrome/Edge 111+, Firefox 113+, Safari 16.4+ for all visual effects).

## Security note
Balances, trades and wallet logic run in the browser. Before handling real money, move them into Supabase Edge Functions / database functions that validate every change on the server.
